# 🌳 Blossom Tree Manager

A comprehensive school check-in application designed to streamline attendance tracking and communication between schools, teachers, parents, and students.

## 📋 Overview

Blossom Tree Manager is a web-based platform that provides:

- **Multi-role access control** (App Owner, Company Staff, School Admin, Teachers, Parents, Students)
- **Real-time attendance tracking** with check-in/check-out functionality
- **Room and user management** for school administrators
- **Parent-teacher communication** tools
- **Multilingual support** (English & Spanish)
- **Notification system** (Email, SMS, Push)

## 🎨 UI Mockup

This repository includes a beautiful interactive HTML mockup showcasing the School Admin dashboard with all major sections:

- Dashboard with room overview and user summary
- Rooms management with detailed room cards
- User management with role-based profiles
- Attendance logs with tabular data

## 🚀 Features (Planned)

### Core Entities

- **School Accounts**: Individual school management
- **Users**: Role-based access (Teachers, Parents, Students, Staff, Admins)
- **Rooms**: Classroom management with grade levels and assignments

### Authentication & Security

- Multi-level role-based access control (RBAC)
- Secure sign-in for all user types
- Permission matrix for different actions

### Attendance System

- Real-time check-in/check-out
- Automated notifications
- Attendance reporting and analytics

### Communication

- Parent-teacher messaging
- Emergency notifications
- Multi-channel delivery (Email, SMS, Push)

## 🛠️ Technology Stack (Proposed)

- **Frontend**: React.js with modern CSS frameworks
- **Backend**: Node.js with Express.js
- **Database**: PostgreSQL with Prisma ORM
- **Authentication**: JWT with role-based permissions
- **Notifications**: Twilio (SMS), SendGrid (Email), Firebase (Push)
- **Deployment**: Docker containers on cloud platform
